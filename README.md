# CineMarcos

CineMarcos es una página web de catálogo de películas.

Permite ver distintas películas y entrar a sus páginas para ver el tráiler, descripción, reseñas y recomendaciones. También cuenta con inicio de sesión y registro.

Para abrir el proyecto, ejecutar `index.html` en el navegador.

Proyecto realizado para el ramo de Desarrollo Web.
